## Kuweka GitHub Pages
1. Ingia GitHub na uchague **New repository**. Ipe jina kama `vansthute-studioz`.
2. Fungua repository, chagua **Add file → Upload files**.
3. Pakia `index.html` pamoja na folder lote la `images` (muundo wake usibadilishwe).
4. Chagua **Commit changes**.
5. Nenda **Settings → Pages**. Chini ya **Build and deployment**, chagua **Deploy from a branch**.
6. Chagua branch `main`, folder `/(root)`, kisha **Save**.
7. Baada ya muda mfupi, kiungo cha tovuti kitaonekana kwenye ukurasa wa **Pages**.

Kubadilisha picha: badilisha picha iliyo ndani ya `images` huku ukitumia jina lilelile, au rekebisha njia ya picha kwenye `index.html`.
